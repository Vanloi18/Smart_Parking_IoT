CẤU HÌNH MẠNG & WI-FI LAN

Để ESP32 DevKit và 2x ESP32-CAM kết nối được tới Backend trên máy tính, tất cả các thiết bị phải nằm trong cùng mạng Wi-Fi LAN:

Vị trí cấu hình duy nhất trên ESP32 DevKit:
src/config/config.h 
inline const char* WIFI_SSID     = "TÊN_WIFI_CỦA_BẠN";
inline const char* WIFI_PASSWORD = "MẬT_KHẨU_WIFI";
inline const char* SERVER_HOST   = "192.168.0.103";
constexpr uint16_t SERVER_PORT   = 5000;
Lưu ý Windows Firewall: Nếu ESP32 không kết nối được tới server, mở Windows Defender Firewall và cho phép cổng 5000 (TCP) hoặc tạm thời tắt Firewall mạng Private.
